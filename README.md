# 🧠 Image Search App

A sleek and modern web app that lets you search for stunning, high-quality images powered by the **Unsplash API**.  
Built using **HTML**, **CSS**, and **JavaScript** — no frameworks, just pure frontend magic ✨.

## 🧩 Features
✅ Search and load high-quality images in real-time  
✅ Download images directly with one click  
✅ “Load More” button to fetch additional results  
✅ Smooth hover animations and gradient UI  
✅ Modal preview and fullscreen image viewing  
✅ Responsive design for all devices  
✅ Toast notifications for downloads and errors  

---

## 💻 Technologies Used
- **HTML5**
- **CSS3 (Animations, Gradients, Flexbox)**
- **Vanilla JavaScript (ES6+)**
- **Unsplash API**
